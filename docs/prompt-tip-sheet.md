# Employer Connected-Care Implementation Blueprint Agent — Prompt Tip Sheet

## Start here
Use the agent to help you **reconcile employer requirements, expose ambiguity, prepare decisions, and turn implementation context into action**.

### A simple prompt framework
**Review [employer implementation scope] + compare [sources] + identify [requirements/decisions] + trace [downstream impact] + recommend [questions/actions/owners].**

Example:
> Review the employer implementation across the CRM, contract, project plan, meeting notes, and implementation standard. Identify unresolved or contradictory requirements, explain what each could affect downstream, and give me the questions and owners needed to resolve them.

## Six prompts to try

1. **Requirements review**  
   Review the employer implementation and tell me what requirements are confirmed, unresolved, or contradictory before we can finalize the launch plan.

2. **Contract-to-execution check**  
   Compare the CRM, contract, project plan, meeting notes, and internal implementation standard. Identify anything the employer expects that is not currently reflected in the implementation plan.

3. **Prepare the next client meeting**  
   Generate the questions I should take into the next client implementation meeting. Prioritize questions that affect eligibility, employee communications, billing, reporting, or downstream member/device readiness.

4. **Turn notes into actions**  
   Convert the latest implementation working-session notes into actions. Assign a suggested owner, due date, dependency, and explain why each action matters to employer launch readiness.

5. **Trace downstream impact**  
   Trace the impact of the unresolved eligibility decision. Show every downstream area that could be affected if we launch before resolving it.

6. **Launch-readiness pre-read**  
   Act as my pre-read for an employer launch-readiness meeting. Give me the current implementation status, unresolved decisions, top dependencies, client actions needed, internal actions needed, and the three items I should not allow to leave the meeting without an owner.

## Stronger questions usually include
- which employer or implementation stage you are reviewing;
- which sources should be reconciled;
- which decision or meeting you are preparing for;
- which downstream areas matter most;
- what output you need: questions, actions, owners, dependencies, or evidence.

### Less useful
> What is missing?

### Better
> Compare the contract, CRM, project plan, and latest meeting notes. Identify any unresolved employer requirements that could affect eligibility, communications, billing, reporting, or member/device readiness, and tell me the question and owner needed to close each gap.

## Human review checklist
Before acting on the output, confirm:
- the contract and current client decision are interpreted correctly;
- conflicting sources are not simply stale versions;
- downstream impacts are plausible for this implementation;
- owners and due dates reflect actual accountability;
- no client decision is inferred when evidence is missing.

**The agent reconciles and recommends. The implementation manager owns the client decision and launch approval.**
